# 大工日報（現場作業日報アプリ）の設定手順

大工さんがスマホで日報（日付・現場・作業内容・時間・材料・数量）を送り、Google スプレッドシートにためるアプリです。
ためた日報から「数量あたりの時間」（歩掛）を自動で計算します。

- 入力画面：`index.html`（スマホ向け）
- プログラム：`Code.gs`（Google Apps Script）
- 要件定義：https://claude.ai/artifact/4Dqh8w7WDvAmkKVPcfJCTd

## 最初の設定（1回だけ。15分ほど）

会社の Google アカウントで、江藤さんか姫野さんが行ってください（その人がスプレッドシートの持ち主になります）。

1. **スプレッドシートを作る**：Google ドライブで新しいスプレッドシートを作り、名前を「大工日報」にします。
   共有は江藤さん・姫野さんだけにします（時給・単価が入るため）。大工さんには共有しません。
2. **プログラムを貼る**：スプレッドシートのメニュー「拡張機能 → Apps Script」を開きます。
   - 最初からある `コード.gs` の中身を消し、`Code.gs` の中身をすべて貼ります。
   - 左の「＋」→「HTML」で、名前を `index` にしたファイルを作り、`index.html` の中身をすべて貼ります。
   - 保存（フロッピーのボタン）します。
3. **シートを作る**：上の関数の選択で `setup` を選び「実行」を押します。
   初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します（「このアプリは確認されていません」と出たら「詳細 → 安全ではないページに移動」）。
   スプレッドシートに「現場」「作業員」「作業内容」「材料」「日報」「日報_作業」「歩掛」のシートができ、作業内容（新築24・リノベ30）が入ります。
4. **作業員と現場を入れる**（スプレッドシートに直接）
   - 「作業員」：作業員ID（W01, W02 …）、氏名、有効（TRUE）、暗証番号（任意・4桁）、時給（任意）。
   - 「現場」：現場ID（S01, S02 …）、現場名、種別（新築／リノベ）、状態。**状態が「進行中」の現場だけ**が入力画面に出ます。
5. **公開する**：Apps Script の右上「デプロイ → 新しいデプロイ」。
   - 種類の選択（歯車）で「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**kokorosya.co.jp 内の全員**（会社の Google アカウントを持つ人だけが開ける。2026-11-24 決定）
   - 「デプロイ」を押し、表示された「ウェブアプリの URL」を控えます。
6. **大工さんに URL を送る**：LINE やメールで URL を送ります。大工さんはスマホのブラウザで**会社の Google アカウントにログインしてから** URL を開き、「ホーム画面に追加」します。個人のアカウントにもログインしていると「現在ファイルを開くことができません」と出ることがあるので、そのときはシークレット（プライベート）ウィンドウで会社のアカウントだけでログインして開きます。
   初回だけ名前（と暗証番号）を選ぶと、次からはその端末で自動で選ばれます。

## ふだんの使い方

- **大工さん**：アイコンから開く → 現場 → 作業内容 → 時間（1時間刻み）→ 材料 → 数量 → 送信。材料は一覧から選び、無ければ「その他（書く）」、使っていなければ「なし」。準備・片付けなど数量の無い作業は、材料・数量の欄が出ません。
  1日に複数の作業・現場があれば「＋ 作業を追加」でまとめて送ります。送信した日のうちなら、開き直して直せます。
  前日・休日の分は日付を変えて送れます。送る前の入力はスマホに自動で残ります。
- **管理者**：スプレッドシートの「歩掛」シートに、種別×作業内容×材料ごとの合計時間・合計数量・時間／数量が出ます。
  「（材料をまとめた全体）」の行は、材料を問わない作業内容全体の値です（実績が少ない材料の目安）。
  日報が届くたびに計算し直します。手で直したあとはメニュー「大工日報 → 歩掛を計算し直す」を押してください。

## 一覧を変えるとき（スプレッドシートを直すだけ）

- **作業内容を増やす**：「作業内容」に1行足します。作業IDは他と重ならない新しいもの（例 N27, R25）にします。**今ある作業IDは変えないでください**（日報と結び付いています）。
- **材料**：「材料」に行を足すと、入力画面の材料の一覧に出ます。H列「使う作業」に作業内容の名前を「、」で区切って書くと、その作業のときだけ出ます（空ならすべての作業で出る）。材料名と規格はつなげて表示します（例：無垢オーク 15mm）。単価は入力画面には出ません。単価を変えるときは、行を書き換えずに新しい行（同じ材料名・新しい単価・いつからの単価か）を足し、古い行の有効を FALSE にします。
- **大工さんが辞めたとき**：「作業員」の有効を FALSE にします（過去の日報は残ります）。

## プログラムを更新するとき（URL を変えずに）

大工さんのホーム画面のショートカットはそのまま使えます。**「新しいデプロイ」は使わない**でください（別の URL が増え、大工さんの画面は古いままになります）。

1. スプレッドシート「大工日報」を開き、「拡張機能 → Apps Script」
2. 左の「コード.gs」を開き、中身を全部消して（Ctrl＋A → Delete）、新しい Code のテキストを全部貼る（Ctrl＋V）
3. 左の「index.html」を開き、同じように新しい index のテキストに貼り替える（変更が Code だけのときは不要）
4. 保存（Ctrl＋S、またはフロッピーのボタン）
5. 右上の「デプロイ」→「**デプロイを管理**」
6. 左に出ている今のデプロイ（「アクティブ」）を選び、右上の**鉛筆のマーク（編集）**を押す
7. 「バージョン」の欄で「**新バージョン**」を選ぶ（説明は空でもよい。例：材料の欄を追加）
8. 「アクセスできるユーザー」が「kokorosya.co.jp 内の全員」のままか確かめる
9. 「**デプロイ**」を押す。出てきた URL が前と同じ（末尾 `/exec`）なら完了
10. スマホのショートカットから開き直して、新しい画面になったか確かめる。古いままなら、一度閉じて開き直すか、画面を下に引っぱって再読み込みする

許可（承認）の画面がまた出た場合は、最初の設定のときと同じように許可します（使う権限が増えたとき）。

## 注意

- 入力画面を開けるのは会社の Google アカウントを持つ人だけです。大工さん全員に @kokorosya.co.jp のアカウントが要ります。
- 時給・単価・原価は、スプレッドシートを共有した人（江藤さん・姫野さん）だけが見られます。管理者用の画面（原価・見積）は次の段階で作ります。
- 入力忘れの知らせ（17:30 など）は、まだありません。
