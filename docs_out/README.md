## スライドの構成

1. 表紙：対象は2階建て・非線引き区域・用途地域の指定なし、住宅 → 旅館
2. 01 手続き：旅館部分が200㎡超なら確認申請が必要。200㎡以下は不要だが基準への適合義務は残る
3. 02 避難：廊下幅（片廊下1.2m・中廊下1.6m）、敷地内通路1.5m、2階からの避難階段の寸法と距離
4. 03 火災への備え：内装制限、界壁、異種用途区画
5. 04 設備・構造：採光・換気・非常用照明・床荷重、消防法・旅館業法
6. 05 浄化槽：人槽算定（2026-11-06 追加）
   - 住宅（大分県）：延べ面積160㎡以下5人、160㎡超7人（JIS では130㎡が分かれ目）
   - 大分県の取扱い：くみ取り・単独処理から合併処理へ設置替えする一戸建ては、160㎡超でも条件付きで5人槽を認める（適用願・使用水量計算書・誓約書を設置届に添付）
   - 旅館：宴会場なし 0.075×A、宴会場あり 0.15×A、簡易宿所など P（定員）
   - 計算例：150㎡・宴会場なし → 住宅なら5人槽、旅館は11.25人 → 例として14人槽
